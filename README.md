# Hardik Jain — Personal Portfolio

An experimental, minimal, editorial-style personal portfolio website built with React, TypeScript, and Framer Motion.

## Features
- **Cinematic Scroll Transition**: Smooth scroll-driven background transition from bold red to warm cream.
- **Editorial Typography**: Large, impactful typographic hierarchy with generous negative space.
- **Interactive Repulsion & Mild Glow**: Words organically part ways and cast a soft red glow upon cursor proximity.
- **Research Experience & Projects Showcase**: Structured showcase of research experience and deep learning / blockchain projects.
- **Fully Responsive**: Optimized for desktop and mobile devices with fluid clamp typography and dynamic viewport units.

## Tech Stack
- React
- TypeScript
- Vite
- Framer Motion
- React Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
